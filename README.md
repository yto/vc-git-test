## カフェオレ

カフェオレは、フランス語で「コーヒー牛乳」を意味する飲み物です。濃いめに淹れたコーヒーに、温めた牛乳をほぼ同量注いで作ります。コーヒーの苦みを牛乳がやわらげるので、ブラックが苦手な人でも飲みやすく、朝食のパンとの相性もよい定番です。フランスでは、ボウルのような大きなカップで両手で包んで飲む習慣があります。イタリアのカフェラテも似ていますが、こちらはエスプレッソをベースにする点が違います。
